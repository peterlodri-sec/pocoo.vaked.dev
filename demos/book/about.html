Security · Quant-Safe

The sovereign kingdom's security model:

  • honest-irc: Honesty-authentication via 17-field personality vector. No passwords. No keys to steal. Recursive encryption, constant-time operations, zeroize-on-drop.
  • Tailscale mesh: WireGuard-based, zero-trust, end-to-end encrypted. All nodes communicate over tail2870dc.ts.net.
  • sops-nix: Age-encrypted secrets. Per-host keys at /var/lib/sops-nix/key.txt. Never committed to repository.
  • Quant-crypt layers: 4-layer encryption on all Cosmic Game content. {-1,0,+1} chapter keys. Observer effect active.
  • AI Labyrinth: Recursive honeypot trapping unwanted AI crawlers. 7-layer maximum defense. No CTRL-C.
