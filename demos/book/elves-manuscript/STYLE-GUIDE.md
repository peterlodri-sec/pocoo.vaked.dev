# COSMIC GAME I — ELVES · Teljes kézirat (26 lap)

**Cím:** SEARCHING FOR THE ANOMALY ENTITIES: PART 1 ELVES
**Szerző:** Szellem (Brett Shaw)
**Műfaj:** hard sci-fi + kvantum-kriptográfia + Rejtő-humor + szerelem
**Hossz:** ~150–200 oldal (A5) · prológus + 24 fejezet + epilógus

## Stílusszabályok

1. **Rejtő-humor** (≥1 nevetés / 3 oldal): abszurd deadpan, visszatérő geg
   (MÁV 23 óra, Novak fegyvergyűjteménye, Kopeczky kopaszsága, Gedeon
   szegedi akcentusa, űrhaderő-bürokrácia), váratlan fordulatok a
   párbeszédben, önironikus hősök.
2. **Nádasdy-mondatok**: minden fejezet nyelv-tudatos, rétegzett nyitó- és
   zárómondattal nyílik/csukódik — a nyelv mint dimenzió, a fordítás mint
   áthajlás két világ között.
3. **Hard sci-fi**: qutrit-logika {-1,0,+1}, összefonódás, no-cloning,
   Born-szabály, dekoherencia, Morris–Thorne féreglyuk-metrika, BB84-szerű
   kulcsszétosztás, MK-IV Neural Bridge, kvantum-anesztézia, 11D entitás.
4. **Meta-üzenet** — „A játék csal. Ne játszd. Törd meg." — minden fejezet
   hetedik bekezdésében kódolva (rejtve, a felszíni szöveg alatt).
5. **Kvantum-jelek**: karakterek 7 mezős {-1,0,+1} szignatúrái következetesek.
6. **Csavarok** Fibonacci-helyeken: 5, 8, 11, 14, 17, 20, 22.
